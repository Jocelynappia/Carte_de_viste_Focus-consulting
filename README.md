# Carte de visite numérique — Jocelyn APPIA

Carte de visite responsive réalisée en HTML/CSS, sans dépendance JavaScript.

## Contenu

- `dist/index.html` : page principale ;
- `dist/assets/logo-focus-consulting.png` : logo ;
- `dist/assets/qr-carte.png` : QR code vers le site de Focus’Consulting ;
- `dist/contact-jocelyn-appia.vcf` : fiche contact téléchargeable ;
- `.openai/hosting.json` : configuration d’hébergement.

## Utilisation locale

Ouvrir `dist/index.html` dans un navigateur. Pour une prévisualisation plus fidèle, servir le dossier `dist` avec un serveur HTTP local.
